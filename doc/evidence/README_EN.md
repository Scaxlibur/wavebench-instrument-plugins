# Plugin Acceptance and Historical Evidence

[中文](README.md)

This page provides one navigation surface for manual audits, development milestones, conformance records,
RFCs, and hardware acceptance evidence in the plugin repository. It is not the source of truth for current
model support or capabilities, and a listed record does not imply that its subject has been released.

For current plugin metadata and capabilities, use the [generated plugin catalog](../reference/plugin-catalog-en.md)
and the package's production descriptor. For WaveBench public contracts and CLI behavior, use the
[WaveBench Core documentation](https://github.com/Scaxlibur/wavebench/tree/master/docs).

## Cross-plugin contracts

- [Plugin-side RFC index](../rfcs/README.md) (Chinese): separates proposals still gathering evidence, current Core contracts, and plugin-side history.
- [Scope R1.3 review text](../archive/rfcs/WaveBench_scope通用扩展接口RFC.md) (Chinese): plugin-side review archive from before Core acceptance.
- [Scope R1.3 A1 acceptance gate](../archive/rfcs/WaveBench_scope通用扩展接口RFC-R1.3-acceptance-addendum.md) (Chinese): pre-registration plugin-side acceptance archive.
