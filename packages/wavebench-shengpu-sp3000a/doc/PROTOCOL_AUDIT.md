# SP3000A 远控协议与能力审计

[English](PROTOCOL_AUDIT_EN.md)

本文是基于厂商资料重新整理的项目原创审计，不替代厂商手册，也不表示对应功能已经通过实机验收。它用于冻结首版驱动的安全边界、数据语义和分级探测顺序。

## 审计结论

SP3000A 具备成为 WaveBench 原生扫频分析仪的基本协议能力：可查询身份和主要状态，可配置点频/扫频源，可选择内外触发和平均，可读取幅频、相频、标记及部分仪器端分析结果。

首版必须保持以下边界：

- 仪器类型采用通用的 `sweep_analyzer`；`frequency_response` 是数据与能力域，不是第二种仪器类型。
- 默认关闭 `OUTPRFORM:CONT`，仅用显式 `OUTPRFORM?` 获取一条有限曲线。
- 不把一次底层 `read()` 当作完整响应；transport 必须按终止符或预期 token 数累计数据。
- 不根据 C 风格字段声明猜测 `OUTSTATEC?` 的线上编码、对齐或字节序。
- 状态快照与恢复以独立、稳定的查询为真源；`OUTSTATEC?` 只作为待验证的原始证据。
- 不把绝对电平 dBm、相对增益 dB 和线性电压混为同一幅度单位。
- 不根据起止频率和点数静默伪造“设备返回的频率轴”；推导轴必须明确标记为 `derived`。
- 外检波、鉴频、反射/驻波和连续 streaming 均为选件或高副作用能力，首版不默认开放。
- 不自动执行 `*RST`、`PRES`、保存/调出状态、修改时钟/语言或打开 RF 输出。
- 写操作、触发和输出控制不得盲目重试。

## 证据等级

| 等级 | 含义 | 可用于 |
|---|---|---|
| 手册声明 | 厂商资料明确描述，但尚未在目标设备验证 | 设计候选、探测计划、保守范围 |
| 实机观察 | 在一台目标设备上重复观察到 | 型号/固件限定的实现与测试 |
| 稳定契约 | 手册、实机和离线测试三者一致 | 公共 API、默认行为和发布声明 |
| 未知 | 文档缺失、矛盾或无法唯一解析 | 必须 fail closed 或标记 unsupported |

任何能力从“手册声明”提升为“稳定契约”前，都必须记录 transport、固件、前置状态、返回格式、副作用和恢复结果。

## 通信与会话

### 手册声明

- 接口：RS-232、USB Device、LAN；GPIB 为可选项。
- 文本命令为 ASCII SCPI 风格。
- RS-232 波特率候选：2400、4800、9600、19200、38400、115200。
- 无校验对应 8 数据位；奇/偶校验对应 7 数据位。
- 命令结束符为 LF（`0x0A`）。
- `*IDN?` 返回设备身份。
- 收到远控命令后仪器进入 RMT；`SYSTem:LOCal` 用于返回本地。

### 仍未冻结

- 停止位、软件/硬件流控和响应结束符。
- CRLF 是否被接受、是否有命令回显。
- LAN/USB 的会话 framing、超时和最大响应长度。
- 写命令是否逐条返回 `OK`；手册只有概括性说明。
- `SYSTem:LOCal` 返回 `LOC` 后连接是否保持可用。

transport 必须显式配置串口参数和读写终止符，不得把常见 RS-232 习惯当作设备事实。首个 driver 不应依赖标准 SCPI 错误队列，因为资料没有声明 `SYST:ERR?`、`*CLS`、`*ESR?`、`*STB?` 或 `*OPC?`。

## 设备私有错误

设备资料定义 `ERRORNo00` 至 `ERRORNo08`，分别覆盖格式错误、当前状态无效、超限、禁止零值、禁止负值、浮点格式错误、数字词法错误、无有效数据和数据位数超限。

这些错误均应映射为确定性、不可自动重试的驱动错误。驱动应保留脱敏后的原始响应，并在必要时重新查询状态；不得把它们套入通用 SCPI 负数错误码模型。

## 信号源与扫频状态

首版快照候选如下：

| 状态 | 查询 | 关键语义 |
|---|---|---|
| 工作模式 | `FUNC?` | `CW` / `SWEEP`；切换可能清零频偏 |
| RF 输出 | `RFSTAT?` | 危险状态，配置期间默认保持关闭 |
| 输出电平 | `POWEr?` | 查询按 dBm 解释；恢复需与 RF 状态分离 |
| 输出阻抗 | `OUTOHMSEL?` | 50 Ω / 75 Ω，影响电平解释 |
| 频率窗口 | `CENS?` 或 `STAS?` | 中心/带宽与起止频率是同一状态的两种视图 |
| 点频 | `CWFREQ?` | 仅 CW 计划使用 |
| 频偏 | `FREQOFFSET?` | 会影响点频和扫频显示/输出 |
| 扫描时间模式 | `SWETAUTO?` | `AUTO` / `MANU` |
| 扫描时间 | `SWET?` | 手动请求值不等于实际完成时间 |
| 频率轴模式 | `SWET:MODE?` | `LIN` / `LOG`，与显示模式不同 |
| 平均 | `SWET:AVER?`、`SWET:AVER:STATe?` | 次数与启用状态必须分别保存 |
| 扫描方式 | `TRIM?` | `CONT` / `SING`，与数据连续上传不同 |
| 触发 | `EXTT?` | 内部/外部；外触发会改变单次/连续语义 |

恢复必须避免非法中间状态：频率窗口优先用成对命令恢复；平均先恢复次数再恢复开关；工作模式和主频率恢复后再恢复频偏；RF 输出最后处理。取消或异常时默认安全策略是保持 RF 关闭，只有显式的恢复授权才能重新打开原输出。

SP30120A 的保守型号边界暂定为：

- 频率：20 Hz–120 MHz；
- 输出电平：−80 dBm 至 +10 dBm；
- 输出阻抗：50 Ω / 75 Ω；
- 手动扫描时间：300 ms–100 s；
- 平均次数：1–10000；
- 返回点数：20–730。

这些是型号能力上限，不是 WaveBench 默认安全限值。实际任务仍需更严格的用户安全配置。

## 曲线输出

### 文档可确定的布局

`OUTPRFORM:MODE` 可选：

- `AMPT`：`A[0] ... A[P-1]`；
- `PHASE`：`φ[0] ... φ[P-1]`；
- `ALL`：先返回 P 个幅度，再返回 P 个相位。

`OUTPRFORM:POINT:DATA` 的范围为 20–730；`OUTPRFORM:POINT ON` 使用配置点数，`OFF` 使用设备最大点数。当前曲线使用 `OUTPRFORM?`，保存曲线使用 `OUTPMEMOV n?`。手册将曲线描述为逗号分隔浮点数。

### 文档不能确定的内容

- 响应终止符、尾逗号、空白和科学计数法是否固定；
- 是否存在 IEEE 488.2 block header；
- 一条响应是否会被底层分片或与下一条粘连；
- `CONT ON` 时两条曲线如何分界、是否一轮扫描对应一帧；
- `POINT OFF` 返回的额外点是内部采样、插值、重复还是填充；
- `ALL` 与幅/相测量开关不一致时的载荷行为；
- 线性/对数轴的端点包含关系和离散公式；
- ABS、REL 和线性显示下，幅度数组的真实单位。

因此首版 parser 必须接收预期模式、预期点数和当前显示/测量状态；数量不符、非有限值、模式冲突或单位不明时应返回不完整结果或报错，不能补零或猜测。

## 频率轴与幅度语义

频率轴必须具有来源：

- `device`：设备显式返回每个频点；
- `derived`：由已查询的起止/中心带宽、轴模式和点数推导；
- `unknown`：无法可靠重建。

首版资料没有显示设备随 `OUTPRFORM?` 返回频率数组，因此预计使用 `derived`，但必须先通过实机验证端点公式。未验证前应允许 `frequency_hz=None`，不能为满足数据模型而生成貌似精确的轴。

幅度语义至少区分：

- 绝对输入电平：dBm；
- 相对输出的增益/衰减：dB；
- 线性显示值：V 或 mV；
- 未知：保留原始 token 与上下文。

相位单位候选为 degree。所有数组必须检查长度一致和有限性。

## 输入、检波和测量开关

内检波可配置 50 Ω、75 Ω或高阻输入；外检波需要选件。外检波极性、量程和探头校正均只能在 capability 明确声明选件存在时使用。

`AMPMEAS` 与 `PHAMEAS` 不能同时关闭，关闭其中一项可能自动打开另一项。恢复时必须把二者视为一个耦合状态，不得只回放单个开关。

显示刻度、参考电平、参考位置和相位刻度属于表现层状态，不应进入通用频率响应数值模型。ABS/REL 没有找到稳定的独立远控命令，应作为未知状态处理。

## Marker 与仪器端分析

仪器提供最多五个 marker，可查询频率、幅度、相位和 delta。WaveBench 可将只读结果标准化为 `MarkerReading`，但 marker 显示、搜索和连续跟踪具有状态副作用。

−3 dB、−20 dB、Q、峰谷、反射系数和 VSWR 等结果必须标记 `method=instrument`。这些功能存在互斥、持续追踪、自动移动 marker 或校准前置条件；首版只定义结果容器，不提供通用写工作流。

反射/VSWR 依赖夹具、选件和“全反射”基准，必须 option-gated，不能因为型号属于 SP3000A 系列就宣称可用。

## `OUTSTATEC?` 与保存状态

资料列出了一个名为 `NowState` 的 C 风格字段集合，包含电平、平均、扫描时间、显示、marker、阻抗、触发、点数和检波模式等状态，但没有定义线上编码。

首版处理规则：

1. 允许执行显式、只读的 `OUTSTATEC?` 探测；
2. 将完整响应作为受限原始证据保存；
3. 不按 packed struct 解包；
4. 不用它替代逐项状态查询或恢复；
5. 在 ASCII/二进制 framing、字段顺序、大小、端序和对齐实测完成前，不提供 parser。

保存曲线和状态的槽位资料存在 1–9、1–10、1–18 三种冲突。暂定公开曲线槽为 1–10，但第 10 槽仍需实机验证；状态调出属于高副作用操作，不进入首版探测。

## 分级探测计划

### L0：离线 parser 与 FakeTransport

- 解析身份、枚举、科学计数值、成对频率和私有错误码；
- 解析 AMPT/PHASE/ALL 的有限 token 序列；
- 拒绝长度不符、非有限值、尾部垃圾和单位歧义；
- 验证 snapshot/restore 顺序，但不打开 transport；
- 验证取消、超时和错误不会触发盲目重试。

通过门槛：完全离线，所有未知协议点有显式失败测试。

### L1：只读 query

候选顺序：

1. `*IDN?`；
2. `OUTPRFORM:CONT?`；
3. 工作模式、RF、电平、阻抗、频率窗口、时间、轴模式、平均、触发和扫描方式；
4. 幅/相测量开关、检波模式和输入阻抗；
5. 点数和返回模式；
6. `OUTPRFORM?`；
7. marker 只读查询；
8. `OUTSTATEC?` 原始证据。

通过门槛：每条 query 连续重复成功，响应边界明确，设备前后关键状态一致，真实资源和身份细节不进入公开记录。

### L2：不改变 RF 的配置并恢复

先确认 RF 关闭，再单项修改点数、返回模式、显示无关配置或扫描参数；每次都执行“快照→设置→查询确认→恢复→查询确认”。禁止复位、保存/调出状态和 continuous upload。

通过门槛：所有字段均可恢复；任何隐式联动被记录；失败后 RF 仍关闭。

### L3：受控输出与测量

在确认接线、负载、阻抗、频率和电平安全限值后，执行直通校准和受控 DUT 测试。输出开启必须是显式授权；finally 路径优先安全关断，再按授权决定是否恢复原状态。

通过门槛：幅频/相频 trace 可重复，轴和单位已验证，仪器端结果与 WaveBench 或独立仪器交叉验证一致，恢复路径通过故障注入。

## 首版非目标

- 连续曲线 streaming；
- 自动 `*RST` / `PRES`；
- 保存或调出工作状态；
- 自动切换本地/远控；
- 时钟、语言和蜂鸣器管理；
- 外检波、鉴频、反射和 VSWR 写工作流；
- 自动 marker 搜索/跟踪；
- 解析 `OUTSTATEC?` 为 C 结构体；
- 根据未知协议行为自动重试。

## M1 公共契约输入

核心公共模型应只表达厂商无关语义：

- `SweepPlan`：CW/SWEEP、频率窗口、线性/对数、自动/手动时间、连续/单次、内/外触发、平均、点数和源输出计划；
- `FrequencyResponseTrace`：幅度、相位、频率轴、单位、轴来源、完整性、时间戳和原始证据引用；
- `SweepAnalyzerSnapshot`：可独立查询和恢复的稳定字段；
- `MarkerReading`：频率、幅度、相位和 delta；
- `InstrumentMeasurementResult`：名称、值、单位、仪器/核心方法来源；
- `TraceIntegrity`：完整性、预期/实际点数和警告。

SP3000A 私有命令、选件枚举和 `NowState` 字段不得进入核心公共 API。
