# 本地厂商资料 / Local vendor material

将 SP3000A 系列手册的本地 Markdown 版本放在本目录，推荐文件名：

```text
SP3000A_manual.md
```

Place the local Markdown version of the SP3000A-family manual in this directory. The recommended filename is shown above.

除本说明外，本目录内容由仓库级 `.gitignore` 排除。请勿强制加入 Git，也不要在厂商资料中混入真实设备地址、序列号、凭据或实验日志。

All files in this directory except this README are excluded by the repository-level `.gitignore`. Do not force-add them, and do not mix real resources, serial numbers, credentials, or laboratory logs into vendor material.
