# SDG2000X 调制协议与波形验收

[English](SDG2000X_MODULATION_ACCEPTANCE_EN.md)

## 结论

2026 年 8 月 21 日，一台 `SDG2122X` 固件 `2.01.01.39R7T2` 完成 AM、DSB-AM、FM、PM、PWM、ASK、FSK 与 PSK 的输出 OFF 协议轮询和 A4 波形验收。所有模式均使用内部调制源；载波幅度为 2 Vpp，AM 50% 深度的最坏包络预算为 3 Vpp。最大实测 3.12 Vpp，低于 9 V 停止阈值和 10 Vpp 硬上限。

现有核心调制 profile 在 `enabled=False` 时仍要求完整内部源参数，而 SDG 关闭时只返回 `STATE,OFF`；核心模型的内部调制频率上限也低于 SDG 数据手册的 1 MHz。因此插件没有填入伪默认值，没有声明有损调制 capability。改进方向见 [Source V2 RFC](RFC_SOURCE_V2_CAPABILITY_STATE_SAFETY.md)。

## 环境与安全边界

- WaveBench：0.8.23。
- 插件：`wavebench-siglent-sdg2000x` 0.7.0。
- 信号源：`SDG2122X`，固件 `2.01.01.39R7T2`。
- 示波器：`RTM2032`，固件 `06.010`。
- 接线：信号源 CH2 → 示波器 CH2，高阻输入。
- 模拟/数字调制载波：Sine、20 kHz、2 Vpp、0 V 偏置；PWM 为 10 kHz Pulse。
- 内部调制/键控频率：1 kHz。
- AM 深度：50%；FM 频偏：2 kHz；PM 相偏：90°；PWM `DDEVI`：20%；FSK 跳频：25 kHz。

每种模式均在输出 OFF 时配置并完整查询；采集前单独开启输出，采集后立即关闭。外部调制源未接线，本轮不声明外部调制验收。

## 协议轮询

输出全程 OFF 的协议轮询验证了 8 种类型的实际字段：

| 类型 | 关键实机回读 |
| --- | --- |
| AM | `MDSP,SINE`、`SRC,INT`、`FRQ,1000HZ`、`DEPTH,50` |
| DSBAM | `MDSP,SINE`、`SRC,INT`、`FRQ,1000HZ` |
| FM | `FRQ,1000HZ`、`DEVI,2000HZ` |
| PM | `FRQ,1000HZ`、`DEVI,90` |
| PWM | `DEVI,4.9985e-05S`、`DDEVI,49.985`，后续以 `DDEVI,20` 明确设置百分比偏差 |
| ASK | `SRC,INT`、`KFRQ,1000HZ` |
| FSK | `KFRQ,1000HZ`、`HFRQ,25000HZ` |
| PSK | `KFRQ,1000HZ`、`PLRT,POS` |

PWM 实机响应证明 `DEVI` 是秒制宽度偏差，`DDEVI` 才是百分比占空比偏差。协议轮询执行 90 次查询、82 次写入；全部写入已完成，未知结果为 0。结束后 `MDWV STATE,OFF`，基础波恢复 Sine / 1 kHz / 4 Vpp，两路 OFF。

## 波形结果

每种模式采集 10,000 点。固定频点幅度使用 Hann 窗复数投影；包络使用解析信号；FSK 使用平滑瞬时频率；PSK 以 20 kHz 下变频后的基带极性验证。

| 类型 | 关键物理证据 | 实测 Vpp |
| --- | --- | ---: |
| AM | 包络 5%/95% 为 0.502/1.489 V，估计深度 49.6% | 3.120 V |
| DSB-AM | 19/21 kHz 边带 0.499/0.498 V，20 kHz 载波仅 0.0007 V | 2.160 V |
| FM | 19/21 kHz 边带 0.577/0.578 V；瞬时频率 20%/80% 为 18.46/21.57 kHz | 2.160 V |
| PM | 19/21 kHz 边带 0.565/0.565 V；瞬时频率 20%/80% 为 18.77/21.20 kHz | 2.160 V |
| PWM | 周期占空比 5%/95% 为 31.0%/69.5% | 2.160 V |
| ASK | 包络 5%/95% 为 0.034/1.056 V | 2.160 V |
| FSK | 平滑瞬时频率 20%/80% 为 19.95/25.08 kHz | 2.160 V |
| PSK | 下变频基带正/负极性占比 51.9%/48.1%；19/21 kHz 分量 0.650/0.619 V | 2.160 V |

所有波形绝对值保持在 ±1.56 V 内，均值接近 0 V，示波器无过载。

## 覆盖边界

- 只验收内部调制源；EXT、CH1/CH2 交叉调制没有相应物理接线。
- 数据适用于当前 SDG2122X 固件，不外推到 SDG2042X/SDG2082X。
- 数字键控验证功能行为与频谱/包络，不是调制误差、EVM 或相位噪声校准。
- 由于关闭态和字段范围无法无损映射当前核心 profile，本轮保留为受管协议与 A4 证据，不声明产品 capability。
