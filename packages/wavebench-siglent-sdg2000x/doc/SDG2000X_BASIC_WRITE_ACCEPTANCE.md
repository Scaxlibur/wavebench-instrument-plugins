# SDG2000X 基础写入实机验收

[English](SDG2000X_BASIC_WRITE_ACCEPTANCE_EN.md)

## 结论

2026 年 8 月 21 日，`wavebench-siglent-sdg2000x` 0.7.0 在一台 `SDG2122X` 的 CH2 上完成主仓库现有基础 Source 写接口验收：

- `source.set_frequency`；
- `source.set_function`；
- `source.set_amplitude_vpp`；
- `source.set_square_duty_cycle`；
- `source.output`。

周期波形、实时频率/幅度/占空比修改均通过驱动完整回读和 RTM2032 闭环测量。最大实测 Vpp 为 4.24 V，低于 10 Vpp 硬上限；示波器无过载，配置快照无漂移。最终恢复 Sine、1 kHz、4 Vpp，信号源 CH1/CH2 均为 OFF。

Noise 与 DC 仅完成输出 OFF 条件下的配置回读。现有核心 `SourceService.set_output` 对 `SourceStatus.amplitude=None` 调用 `isfinite()`，会在任何仪器写入前抛出 `TypeError`。插件不伪造 Vpp 值，也不修改核心；该问题进入多厂商 Source 状态/安全 RFC。

## 环境与边界

- WaveBench：0.8.23。
- 最终插件版本：`wavebench-siglent-sdg2000x` 0.7.0。
- 信号源：`SDG2122X`，固件 `2.01.01.39R7T2`。
- 示波器：`RTM2032`，固件 `06.010`。
- 接线：信号源 CH2 → 示波器 CH2；示波器输入保持高阻。
- 核心 Vpp 上限：10 Vpp。
- 未发送 `*RST`、网络配置、持久化存储、任意波上传或 raw SCPI 旁路命令。

## 失败关闭证据

首次函数切换验收在 Sine→Square 后触发 `HARM?` 超时。E05C 明确规定 Harmonic Command 仅在基础波形为 SINE 时可用；旧实现把 `HARM?` 当成无条件安全查询，导致 transport 会话进入故障状态，原会话无法验证 OFF。

处理过程：

1. 立即停止后续波形测试；
2. 使用全新 WaveBench 会话向需要收敛的通道发送一次 OFF；
3. 独立读取 CH1/CH2，确认两路均为 OFF；
4. 将谐波查询改为按函数激活：非 SINE 不发送 `HARM?`，切回 SINE 时重新查询并比较；
5. 增加「非 SINE 零 HARM 查询」及「切回 SINE 后谐波重新激活」故障测试；
6. 重新执行完整函数验收。

修正提交为 `d7e1b03`。应急 OFF 新会话完成 1 次写入、1 次已完成、0 次未知结果；后续正式验收通过。

## 尚未覆盖

- CH1 因前置谐波状态仍未执行基础写入闭环；插件按设计零写入拒绝。
- `SDG2042X` 与 `SDG2082X` 只有离线合同证据。
- Noise/DC 缺少可复用的核心电压状态与安全预算模型，不能声称已完成输出波形验收。
- 1 µHz、型号最高频率和 0.001%/99.999% 占空比是离线边界，不适合在当前高阻、5 ms 窗口下冒充全量程物理验收。
