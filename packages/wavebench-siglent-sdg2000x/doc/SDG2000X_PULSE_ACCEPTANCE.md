# SDG2000X Pulse 协议与波形验收

[English](SDG2000X_PULSE_ACCEPTANCE_EN.md)

## 结论

2026 年 8 月 21 日，一台 `SDG2122X` 固件 `2.01.01.39R7T2` 完成 Pulse 参数协议与 A4 波形验收。1 kHz、2 Vpp 条件下，25% 与 65% 占空比分别实测 25.20% 和 64.96%；设定 20/40 µs 上升/下降时间，实测范围为 20.0–20.9 µs 和 39.5–42.4 µs。最大实测 2.16 Vpp，低于 9 V 停止阈值和 10 Vpp 硬上限。

协议轮次证明 `WIDTH`、`DUTY`、`RISE`、`FALL` 与 `DLY` 均可独立写入并回读；当前固件的秒值可能没有 `S` 后缀。正式轮次的 38 次写入全部完成，未知结果为 0。

现有核心 `SourcePulseProfile` 要求权威 `hold` 为 `WIDTH` 或 `DUTY`。SDG 查询同时返回宽度与占空比，却不返回 hold 状态。实机改变频率时观察到宽度保持，但该行为不是协议中的权威字段，不能据此伪造可往返的 hold。插件因此没有声明有损 Pulse profile/control capability。通用改进方向见 [Source V2 RFC](RFC_SOURCE_V2_CAPABILITY_STATE_SAFETY.md)。

## 环境与安全边界

- WaveBench：0.8.23。
- 插件：`wavebench-siglent-sdg2000x` 0.7.0。
- 信号源：`SDG2122X`，固件 `2.01.01.39R7T2`。
- 示波器：`RTM2032`，固件 `06.010`。
- 接线：信号源 CH2 → 示波器 CH2，高阻输入。
- 基准：Pulse、1 kHz、2 Vpp、0 V 偏置。

所有参数均在输出 OFF 时配置；Harmonic、Modulation、Sweep、Burst、Combine、Noise Add 与 Coupling 均确认关闭。波形采集结束后立即关闭输出。

## 协议结果

| 操作 | 回读结果 |
| --- | --- |
| `DUTY,25` @ 1 kHz | 25%，`WIDTH=250 µs` |
| 随后改为 2 kHz | `WIDTH=250 µs` 保持，`DUTY=50%` |
| `WIDTH,300 µs` @ 1 kHz | 300 µs，`DUTY=30%` |
| 随后改为 2 kHz | `WIDTH=300 µs` 保持，`DUTY=60%` |
| `DLY` | 0 与 100 µs 均回读 |
| `RISE/FALL` | 20/40 µs 均回读 |

这些结果表明当前固件在两种设置顺序下都维持绝对宽度，但查询没有返回「保持宽度」模式位。核心若把读取结果再写回为 `hold=DUTY`，未来改频行为会发生变化；把观察到的行为硬编码成所有型号、所有固件的永久语义也不安全。

`WIDTH`、`RISE`、`FALL` 与 `DLY` 的实机响应使用裸秒值，不带 `S`。严格解析应允许有限裸秒值与带 `S` 秒值，但继续拒绝未知单位、重复字段和非有限数。

## 波形结果

示波器以平台 5%/95% 电平建立 10%/50%/90% 阈值；周期和脉宽只使用完整穿越 10%→90% 或 90%→10% 的合格边沿，以排除下降沿振铃造成的伪交点。

| 配置 | 频率 | 脉宽 | 占空比 | 上升 10–90% | 下降 90–10% | 实测 Vpp |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 25% | 1000.0 Hz | 252.0 µs | 25.20% | 20.9 µs | 42.4 µs | 2.16 V |
| 65% | 1000.0 Hz | 649.5 µs | 64.96% | 20.0 µs | 39.5 µs | 2.16 V |

`DLY` 只完成 0/100 µs 协议回读。单路自由运行信号没有独立时间参考，示波器会跟随被测边沿触发，因此本轮不把 DLY 回读写成物理延迟 A4。
