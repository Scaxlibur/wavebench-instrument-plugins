# 本地厂商资料 / Local vendor material

请将 MSO8000 编程手册放在本目录。推荐保留以下两个文件名：

```text
MSO8000_ProgrammingGuide_CN.pdf
MSO8000_ProgrammingGuide_CN.md
```

其中 PDF 是原始对照文件，Markdown 是后续检索和整理使用的转换稿。若采用英文手册或其他版本，请在文件名中保留语言、版本号或发布日期，避免覆盖不同版本。

本目录除本说明文件外的内容由仓库级 `.gitignore` 排除，也会从 distribution 的 sdist 排除。请勿强制加入 Git，也不要在手册或转换稿中混入真实仪器地址、序列号、凭据、波形、截图或实验日志。

Place the original MSO8000 programming guide and its converted Markdown copy in this directory. All files except this README are ignored by Git and excluded from the distribution sdist.
